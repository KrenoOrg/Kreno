# Kit pilote Kreno — bêta privée

## Message d’accueil à adapter

Bienvenue dans la bêta Kreno. Kreno complète votre agenda actuel : lorsqu’un créneau se libère, vous indiquez simplement sa date, son heure et sa prestation. Les clients compatibles présents sur votre liste reçoivent un SMS ; le premier à confirmer reçoit le créneau. Vous gardez ensuite la main pour valider le rendez-vous dans votre agenda habituel.

## Démarrage en cinq minutes

1. Compléter le profil, les prestations et les collaborateurs.
2. Vérifier que la page de liste d’attente est compréhensible pour vos clients.
3. Ajouter une première demande de test avec votre propre numéro.
4. Signaler un créneau de test et confirmer le lien reçu.
5. Vérifier dans votre agenda externe avant de considérer le rendez-vous comme définitif.

## FAQ pilote

**Kreno remplace-t-il mon agenda ?** Non. Kreno ne crée pas de rendez-vous dans Planity ou tout autre agenda.

**Que se passe-t-il si personne ne répond ?** Après expiration, les clients restent sur la liste et pourront être prévenus pour un prochain créneau.

**Que se passe-t-il si deux clients répondent ?** Une transaction serveur attribue le créneau à un seul client.

**Puis-je arrêter les SMS pour un client ?** Oui, un STOP entrant ou enregistré depuis le tableau de bord l’exclut immédiatement des prochains envois.

**Que dois-je signaler pendant la bêta ?** Toute erreur d’attribution, message non reçu, créneau annulé, difficulté de compréhension ou idée d’amélioration. Conserver la date, l’établissement et une courte description du cas.

## Support bêta

Pour toute question ou incident pendant la bêta, écrire à
[kreno.contactfr@gmail.com](mailto:kreno.contactfr@gmail.com). Ne jamais joindre
de liste de numéros de téléphone, de lien de confirmation ou de secret dans un
e-mail de support.

## Point hebdomadaire

Recueillir : nombre de créneaux proposés, créneaux récupérés, incidents, retours clients, temps économisé et demandes prioritaires. Ne jamais partager de liste de numéros de téléphone dans le canal de support.
